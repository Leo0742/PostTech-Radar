# PostTech Radar

[English](README.en.md)

Сервис для первичной обработки обращений Service Desk. Эта версия содержит финальный интерфейс и backend проекта: очередь обращений, классификацию, рекомендации линии, поиск похожих случаев, подтверждение оператором и аналитику SLA.

## Что обновлено

- Полный React-интерфейс: обращения, база, карточка исходной записи и аналитика.
- Импорт Excel, ручной ввод, исправление категории и линии, сохранение подтверждённого обращения.
- Backend с SQLite, поиском похожих случаев и аналитикой сроков, нагрузки, уточнений и участия линий.
- Финальный основной режим: дообученный MiniLM и обученная голова классификации.
- Дополнительная перепроверка: Qwen3-Embedding-4B с LoRA-адаптером и обученной головой.
- Скрипты установки и запуска для Windows, Linux и macOS; загрузка закреплённой ревизии базовой Qwen с Hugging Face.
- Исправлена вёрстка выбора категории и убрана лишняя формулировка про четвёртую линию.

## Публичная версия и файлы для запуска

Код приложения опубликован полностью. Предоставленные обращения заказчика, база и обученные на этих данных бинарные файлы остаются приватными. Скачать их через GitHub или git lfs pull нельзя. Это ограничение касается и дообученных MiniLM-весов, и Qwen LoRA-адаптера.

Для полного запуска нужен разрешённый локальный комплект `data/raw/` и `models/`. Список файлов и контрольные суммы: [SUBMISSION_MANIFEST.md](SUBMISSION_MANIFEST.md). Базовая Qwen скачивается автоматически, но Hugging Face не заменяет наши обученные файлы.

[Подробные команды установки и запуска](docs/LOCAL_SETUP.md) рассчитаны на такой комплект. Без него установщик выдаёт сообщение о недостающих файлах.

Основной MiniLM-режим работает на CPU. Qwen — дополнительная тяжёлая проверка. В локальной проверке на Mac холодный запуск Qwen превысил 180 секунд; успешный полный Qwen-сценарий на этом окружении не подтверждён. Основной сценарий классификации, маршрутизации, поиска и аналитики проверен отдельно.

## Проверка кода без приватного комплекта

Нужны Python 3.12 или 3.13 и Node.js 22.12+.

macOS / Linux:

```bash
git clone https://github.com/Leo0742/PostTech-Radar.git
cd PostTech-Radar
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest backend/tests -q
python -m ruff check backend/app
cd frontend
npm ci
npm test
npm run lint
npm run build
```

Windows PowerShell:

```powershell
git clone https://github.com/Leo0742/PostTech-Radar.git
cd PostTech-Radar
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest backend/tests -q
.\.venv\Scripts\python.exe -m ruff check backend/app
cd frontend
npm ci
npm test
npm run lint
npm run build
```

Тесты, которым нужны исходные обращения или обученные артефакты, пропускаются при отсутствии приватного комплекта. Остальные тесты проверяют код на тестовых данных.

## Как проверить полный сценарий

После установки разрешённого комплекта откройте `http://127.0.0.1:8000`.

1. Добавьте обращение вручную или загрузите Excel.
2. Запустите анализ и откройте уверенность, объяснение категории и рекомендацию линии.
3. Откройте похожий случай и его исходную запись с результатом работ.
4. Подтвердите или исправьте категорию и линию, затем сохраните обращение.
5. Найдите сохранённое обращение в базе.
6. Откройте аналитику и примените фильтры периода, услуги, категории, приоритета и линии.

## Обучение и ограничения

Финальные runtime-пути находятся в `scripts/project_setup.py`. Код дообучения — `scripts/gpu_customer_finetune.py`, сборки голов — `scripts/build_final_finetuned_heads.py`.

Для модели используются только сведения, доступные при регистрации. Итог работ, фактические сроки и линия решения используются для разметки, истории и аналитики. Уверенность — оценка модели, а не гарантия правильности; оператор может изменить решение.

[TRAINING.md](TRAINING.md), [MODEL_CARD.md](MODEL_CARD.md) и материалы в [docs/training](docs/training/) описывают предыдущие эксперименты V5.2 с frozen Qwen 4B/8B. Их метрики не являются оценкой финального дообученного runtime. Исторический README сохранён [отдельно](docs/training/README_V5_2_HISTORY.md).

Это студенческий проект, а не официальный продукт ПочтаТех. [Условия публичной версии](PUBLIC_REPOSITORY_NOTICE.md).
